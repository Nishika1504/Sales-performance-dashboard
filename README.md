# 📌 Project 1: Sales Performance Dashboard

## 📖 Project Overview

The **Sales Performance Dashboard** is an interactive Power BI dashboard designed to analyze sales data and provide useful insights into business performance.

The dashboard helps users understand important sales metrics such as revenue, profit, sales quantity, product performance, regional performance, and sales trends.

## 🎯 Objectives

* Analyze overall sales performance
* Track revenue and profit
* Identify top-performing products
* Analyze sales by region
* Understand sales trends over time
* Create interactive visualizations using Power BI
* Present business insights through an easy-to-understand dashboard

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **Power Query**
* **DAX**
* **Microsoft Excel / CSV**
* **GitHub**

## 📊 Dashboard Features

The dashboard includes:

* Total Sales
* Total Profit
* Sales by Region
* Sales by Product
* Monthly/Yearly Sales Trends
* Profit Analysis
* Interactive Filters and Slicers
* KPI Cards
* Charts and Visualizations
